Простой проект на Python для работы с базой данных SQLite через ORM. Содержит файл Orm.py с реализацией ORM-логики и базу данных DatNew1.db. Для запуска требуется Python 3.x: клонируйте репозиторий и выполните python Orm.py. Внешние зависимости отсутствуют, используется стандартная библиотека sqlite3.
